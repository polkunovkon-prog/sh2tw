# Войны Вольмарских марок — основная кампания (main_v1)

Стратегическая кампания поверх Stronghold 2: северная марка Вольмар, 12 регионов
(6 замков, включая specialty «Логово Волка», и 6 деревень), 5 лордов — игрок
«Константин» (Соколий утёс) и 4 ИИ с характерами: Мёллер Ястреб (ранний агрессор),
Гуннар Бык (строитель крепостей), Олаф Скальд (осадник), Королева Ингрид (дипломат).
Сезонный цикл (4 сезона/год), события живого мира, коалиции против лидера, бои
в живой игре на картах `S2TW_*` или авто-резолвом.

Победа: короткая — уничтожить `l_hawk` и `l_olaf` ≤ 30 сезонов; полная — 9 из 12
регионов ≤ 60 сезонов; после победы — песочница (`sandbox`).

Запуск из корня репозитория (подробности: `docs/install.md`, правила: `docs/player_guide.md`):

```powershell
$env:PYTHONPATH = "tools"; .\.venv\Scripts\python.exe -m sh2tw.shell.api --campaign campaigns/main --port 8402
# браузер: http://127.0.0.1:8402
```

`campaign_state.json` не хранится — оболочка создаст партию при первом запуске
(слепки `history/`, журнал `events.jsonl`). Контракт кампании:
`python3 -m pytest tests/test_campaign_content.py -q`.
