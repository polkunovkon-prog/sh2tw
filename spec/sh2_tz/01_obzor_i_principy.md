# 01. Обзор и принципы

## 1.1. Цель проекта

На базе Stronghold 2 (Firefly Studios, 2005; у заказчика репак, целевая версия — Steam v1.5.0, сверка — эксперимент V5) получить однопользовательскую игру:

1. Старт на стратегической карте, выбор стартового региона.
2. Развитие региона **на тактической карте** — настоящее строительство в SH2, не шаблонная подстановка.
3. Сбор армии и завоевание соседей: полевые бои и штурмы реально отстроенных замков — тоже на тактических картах SH2.
4. Игра до захвата всей карты или до «короткой победы».
5. Соседи-ИИ развиваются по-настоящему (живая экономика и замки в сценах-театрах; между театрами — воспроизводимая внешняя модель развития).
6. ИИ сильнее ванильного **без ресурсных читов**: усиление только через умные данные (шаблоны замков, росписи, тайминги), честность измерима протоколом.

Сюжет не важен. Ритм заказчика («развитие ~10 минут реального времени → стратегическая пауза») реализован как сезонный ход + короткие сцены, при желании ускоряемые клавишами скорости игры.

## 1.2. Что строим (продукт)

Единый проект `sh2tw` из четырёх функциональных блоков:

- **Оболочка кампании** — локальное приложение (веб-интерфейс): карта регионов, панель региона, подготовка боя, итоги, журнал; сезонный цикл; стратегический ИИ соседей; авто-резолв; дипломатия; события.
- **Конвейер сцен** — генератор тактических карт SH2 (патчер заготовок → писатель MapHeader → rehost сейва), раннер (запуск игры, слежение за сейвами), парсер итогов (`.sh2` → `snapshot.json` → `scene_result.json`).
- **Библиотека честного ИИ** — архетипы доктрин (`.aic`-шаблоны, правки `gameRules.dat` на основе `gamerules_fixed.dat`, хореография вторжений) + GA-конвейер отбора.
- **Инфраструктура** — эксперименты, тесты, бэкапы, документация, журнал.

Опциональный пятый блок — **d3d9-мост** (трек 2): телеметрия и автосейв на хуке, поверх sh2-unofficial-patch через `d3d9_chain.dll`. Включается только при успехе V5; система обязана полноценно работать без него.

## 1.3. Принципы (нарушение = баг дизайна)

| # | Принцип | Следствие |
|---|---|---|
| P1 | **Нативные механики прежде всего** | Всё, что умеет движок (эстейты, честь, Invasion, ControlLordsAI, SetAllies), используется как есть; своё пишем только там, где движок не умеет (стратегический слой, ходы, победа кампании) |
| P2 | **Файлы, не память** | Ядро — трек 1: генерация `.s2m`, чтение `.sh2`; ни одного обязательного хука в игре |
| P3 | **Честность ИИ измерима** | Каждый матч проходит протокол учёта (файл 03); превышение допустимого дохода = матч бракуется |
| P4 | **Темп: ≤15 переходов в игру за кампанию** | Правило 15; отслеживается счётчиком оболочки; авто-резолв 40–70 % боёв; «пустых» сезонов подряд ≤2 |
| P5 | **Каждый этап играбелен** | Этап не закрывается, пока его результат не даёт играбельный/проверяемый артефакт |
| P6 | **Fallback у каждого механизма** | У каждого канала (провижининг армий, детект исхода, перенос застройки) прописана лестница fallback'ов (файлы 05, 10) |
| P7 | **Не ломать игру** | Никаких необратимых изменений каталога игры; бэкапы; трек 2 удаляется переименованием одного файла |
| P8 | **Точность бинарной работы** | Никаких «примерно правильных» смещений; round-trip тесты на всех 89 картах и 78 сейвах копии заказчика |

## 1.4. Границы (non-goals)

Не делаем в этой архитектуре: больше 24 регионов; туман войны в Total War-смысле; сложную дипломатию (только война/мир/союз/дань); новые юниты и модели (`.gr2`-анимации не конвертируются — F10); непрерывный мир без загрузок; больше 8 сторон в одной сцене (лимит движка — G1); изменение движковых лимитов (карта жёстко 256×256 высот — F3).

## 1.5. Роли

- **Человек (Константин):** плейтесты; эксперименты в живой игре (файл 10); геймплейные решения и приёмка; финальный баланс; доступ к облачной модели для консультаций и правок ТЗ.

## 1.6. Критерии успеха проекта (сокращённо; полно — файл 11)

- Проходится полная кампания: короткая победа за ≤30 сезонов без выгорания (метрики файла 11), полная — за ≤60.
- ИИ-доктрина побеждает игрока ≥30 % матчей при равных стартах и чистом протоколе честности.
- Расхождение авто-резолва с реальными боями ≤20 % по исходу в калибровочных бинах.
- Ни одного матча ИИ с аномальным доходом за всю кампанию.

## 1.7. Словарь проекта

| Термин | Значение |
|---|---|
| Сезон | Единица времени кампании; 4 сезона = игровой год; в сценах SH2 время идёт месяцами (≈1 месяц ≈ 1 реальная минута на обычной скорости — G2, уточняет V5b) |
| Регион | Узел стратегической карты: замок лорда, деревня-эстейт или пустой узел; владеет одна сторона |
| Сцена | Один запуск SH2: бой, штурм, оборона или развитие-театр; описывается `scene_spec.json`, закрывается `scene_result.json` |
| Rehost | Приём «сейв → карта»: файл `.sh2` переименовывается в `.s2m` и загружается редактором/игрой как карта (V4) |
| Провижининг | Способ доставки армии стороны в сцену (стартовые войска эстейта / Invasion с владельцем / военная казна) |
| Доктрина | Набор данных ИИ: `.aic`-шаблон замка + веса `gameRules` + хореография вторжений; YAML-файл |
| Честность | Отсутствие у ИИ скрытых ресурсов; проверяется учётом доходов по snapshot'ам |
| Переход | Выход из оболочки в живую SH2; бюджет — 15 за кампанию (P4) |
