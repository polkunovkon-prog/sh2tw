# ТЗ: Stronghold 2 × Total War — пакет технического задания v1.0

**Дата выпуска:** 23.11.2026. **Статус:** финальное ТЗ для передачи локальному агенту-исполнителю.
**Основание:** «Предварительный план» (свод отчётов Qwen4 / GLM5.3 / Hermes от 22–23.11.2026) — архитектура §3/§4 плана принята и не пересматривается; все возражения собраны в файле `12` (раздел «Несогласия»).

## Назначение пакета

Пакет — полное техническое задание на реализацию стратегического режима (кампании) поверх Stronghold 2 с боями и развитием на тактических картах самой игры. Исполнитель — **локальный ИИ-агент Hermes с моделью Qwen 3 8B (квантование IQ3_S)** под управлением человека (Константин). Пакет спроектирован под ограничения слабой локальной модели: задачи атомарны, форматы заданы схемами и примерами, каждый этап имеет машинные критерии приёмки.

## Порядок работы (кратко; подробно — в файле 00)

1. Человек выполняет эксперименты V-серии (файл 10) → отчёты кладутся в `experiments/reports/`.
2. Агент выполняет задачи из `task_registry.json` строго по спецификациям файлов 03–08, фиксируя прогресс в `PROGRESS.md`.
3. Каждая задача закрывается только при прохождении машинных проверок из её карточки.
4. Спорные вопросы — в `QUESTIONS.md`; человек подключает облачную модель для консультаций при необходимости.

## Ключевые решения (однострочник для навигации)

- Архитектура: «G» — внешняя оболочка кампании + генератор сцен + файловый трек 1 как ядро; d3d9-мост — опциональное ускорение.
- Сцены: 4 типа (полевой бой, штурм, оборона, развитие-театр) + авто-резолв; армии входят в сцену через **стартовые войска эстейтов** (MapHeader), **Invasion-события с указанием владельца** и/или **военную казну** (золото+честь) — канал закрывается экспериментом V7.
- Перенос отстроенного замка в оборону — через **rehost** (переименованный сейв как карта, V4) с fallback на шаблоны уровней застройки.
- Честность ИИ: измеримый протокол учёта доходов (файл 03, `honesty_report.json`), любое скрытое преимущество бракует матч.
- Победа: короткая (разгром 2 антагонистов, 25–30 сезонов) и полная (контроль 9 из 12+ регионов, 40–60 сезонов).
