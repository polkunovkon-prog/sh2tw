# Протокол разметки 50 general values .aic (ТЗ 08 §8.6; регистр F4)

Источник формата: `ref/OpenSH2-Notes/FileFormats/AIC.md` — секция «General
values (semantics retained as unknown)»: 50 × u32 сразу после N записей
построек. Семантика значений в доках НЕ документирована («retained without
assigning unverified behavior»); в корпусе часто 0xFFFFFFFF. Документировано
только место в раскладке — сами значения reader сохраняет без трактовки.

Инструменты шагов 1–2 — `tools/sh2tw/doctrines/aic_diff.py`:

- `general_values_matrix(aic_dir)` → {файл: [50 значений]}; битые
  (обрезанные) файлы пропускаются с пометкой-warning;
- `matrix_to_csv(matrix)` → CSV длинного формата `filename,position,value`;
- `cluster_report(matrix)` → markdown-таблица по позициям:
  n_unique / min / max / most_common.

## Протокол разметки (4 шага, 08 §8.6)

1. **Матрица.** `general_values_matrix` по всем полным `.aic` корпуса
   (43 из 47; 4 обрезанных тестовых файла поставки пропускаются с пометкой)
   → CSV `filename,position,value` (файл × позиция × значение).
2. **Кластеризация + гипотезы.** `cluster_report`: кластеры значений по
   позициям; сопоставление с документированными характерами лордов (кто
   рашит / строит / стрелкует — статьи fandom/stronghold-nation) → гипотезы
   вида «значение N похоже на агрессию».
3. **A/B-игра (V8b).** базовый лорд → копия с ОДНИМ изменённым значением →
   человек играет 10 минут, фиксирует отличие; форма отчёта —
   `experiments/reports/V8b.json`.
4. **Реестр.** результат — таблица ниже: позиция → гипотеза → статус
   (подтверждено / не подтверждено / неизвестно). **GA использует только
   подтверждённые значения**; всё неизвестное помечается `# UNKNOWN(...)`
   в коде и не участвует в логике (принцип 00 §0.4).
